# Notes From a Passive-Aggressive Fridge

`Your leftovers outlasted your last relationship, and I still don't get a thank you for keeping them cold.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The fridge is passive-aggressively salty that your Tupperware has outlasted your last relationship — and still gets no thanks for keeping it cold. It also judges your midnight snack choices in silence.
